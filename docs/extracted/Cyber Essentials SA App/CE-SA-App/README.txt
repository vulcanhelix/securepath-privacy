====================================================
  Cyber Essentials SA — Desktop App
  CE Framework v3.2 (April 2025) · SA Edition
====================================================

HOW TO RUN
----------
1. Extract this ZIP to any folder on your PC
   e.g.  C:\Apps\CyberEssentialsSA\

2. Double-click:  "Launch Cyber Essentials SA.bat"
   → Opens as a standalone desktop window
     (no address bar, no tabs — looks like a native app)

3. OPTIONAL — Add a shortcut to your Desktop:
   Double-click:  "Add to Desktop.vbs"
   → Creates "Cyber Essentials SA" on your Desktop


REQUIREMENTS
------------
  • Chrome OR Edge must be installed
    (one of these is already on every Windows 10/11 PC)
  • No internet connection needed
  • No installation, no Node.js, nothing else required


SAVE YOUR PROGRESS
------------------
  Click  💾 Save  in the sidebar
  → Downloads a .json file (e.g. CE-SA-progress-2025-03-07.json)

  Click  📂 Load  to restore a saved session
  → Select the .json file you saved earlier


PRINT REPORTS
-------------
  Click the  🖨️ Reports  tab in the sidebar
  → Choose report type and fill in company name
  → Click "Print / Save as PDF"
  → In the browser print dialog, set Destination to "Save as PDF"
