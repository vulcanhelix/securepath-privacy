  SA Privacy & Cybersecurity Framework
  Desktop App — Windows

HOW TO RUN (30 seconds, no install needed)
--------------------------------------------

1. Extract this ZIP to any folder
   e.g. C:\Apps\PrivacyFramework\

2. Double-click:  Launch App.bat

   The app opens as a standalone desktop window
   (no browser address bar, no tabs — looks like a native app)

3. OPTIONAL — Add a Desktop shortcut:
   Double-click:  Create Desktop Shortcut.vbs
   Then launch from your Desktop anytime.


REQUIREMENTS
------------
  Chrome OR Edge must be installed (either one is fine).
  Both are already on almost every Windows 11 computer.
  No Node.js, no install, no internet connection needed.


SAVE YOUR PROGRESS
------------------
  Click the  💾 Save  button in the sidebar
  → Downloads a .json file to your Downloads folder

  Click the  📂 Load  button to restore progress
  → Pick the .json file you saved earlier


PRINT REPORTS
-------------
  Click the  🖨️ Reports  tab in the sidebar
  → Choose report type, fill in company name
  → Click "Print / Save PDF"
  → In the print dialog, set Destination to "Save as PDF"


FILES IN THIS PACKAGE
---------------------
  PrivacyFramework.html       The app itself
  Launch App.bat              Double-click to run
  Create Desktop Shortcut.vbs Add to Desktop
  README.txt                  This file


TROUBLESHOOTING
---------------
  App doesn't open?
    → Make sure Chrome or Edge is installed
    → Right-click Launch App.bat → Run as administrator

  Blank white screen?
    → Wait 3-5 seconds, the app loads locally

  Want to just open in browser?
    → Double-click PrivacyFramework.html directly
