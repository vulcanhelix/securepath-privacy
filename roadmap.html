Decision log

23 Jul 26
DB hosting: self-hosted Supabase on AWS af-south-1 — hosted Supabase has no SA region; SA residency non-negotiable.
23 Jul 26
Isolation: one Postgres, shared schema, forced RLS keyed on auth.uid(); tenant id never accepted from client; isolation test suite is the CI gate.
23 Jul 26
Auth: GoTrue (in-stack, SA-resident). No Clerk — US identity residency weakens the compliance pitch. WorkOS later, narrowly, for Entra SSO.
23 Jul 26
RBAC: 5 fixed roles per spec; one practice per user for MVP.
25 Jul 26
Domain: securepath.dev (Cloudflare). Dev serving via one A record + Caddy on VPS — no self-hosted DNS zone. Supabase API stays localhost-only until prod-style secrets exist (CLI dev keys are public defaults).
25 Jul 26
Dev host hardening: docker publishes to 0.0.0.0 and bypasses ufw, so Supabase ports are blocked at iptables raw PREROUTING (persisted). Never assume a container port is localhost — verify from outside.
